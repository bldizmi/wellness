Community Sharing – Full Frontend Implementation

We already have complete backend support for item sharing, community structure, and photo verification. The goal now is to finish the frontend implementation and improve UX clarity for shared items. Use only existing endpoints, routes, and models. Do not create duplicates.

⸻

✅ What Already Exists (Do Not Rebuild)
	•	/api/item/:id/share — share items with specific users
	•	/api/community/shared — get shared items from my community
	•	shared_with, created_by, verified_by fields exist in the database
	•	Verify flow is fully built (photo upload, AI analysis, feedback stored)
